# GODMOD3STORE-Panel

Loader HUD lisensi (plain Luau, tanpa obfuscate). Cara pakai di executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/SanggonBoy/GODMOD3STORE-Panel/master/Dashboard.lua"))()
```

Masukkan key yang diberikan admin → pilih cheat → EKSEKUSI.

- `Dashboard.lua` = satu-satunya file yang di-push (ini file distribusi publik).
- File lain (`.env`, `private/`, hasil eksperimen) wajib masuk `.gitignore`.
